# 安全

MCP 接口围绕一条不变式构建：智能体可以推进工作，但绝不能动资金。

## 工具类别

工具分为查询、起草、提交三类。每个作用域（`payos:read`、`payos:draft`、`payos:submit`）解锁一个类别。禁止动作既无作用域也无对应工具。

## 人工审批

`submit_for_approval` 将工作提交给 Next PaymentOS 审批队列中的指定负责人。任何操作都不会自动批准。同一主体不得既提交又批准同一对象。

## 隔离

- **Token 隔离** —— token 绝不进入模型上下文、工具结果或日志。
- **租户隔离** —— `tenant_id` 从已验证的 token 读取，绝不从工具参数读取。
- **静态目录** —— 工具集版本化且固定，不进行动态工具注册。

## 安全控制

- **紧急停止** —— 指定负责人可一键禁用整个接口、某个客户端或某个智能体。
- **审计** —— 每次调用都产生可关联、防篡改的事件。
- **速率限制** —— 按工具类别强制执行，并配断路器。

## 文档范围

本页描述目标架构。在通过生产门槛（签约合作伙伴合同、独立安全审查、通过沙盒测试套件、指定运营负责人）之前，线上接口仅限沙盒。
