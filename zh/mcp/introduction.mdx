# 简介

Next PaymentOS MCP 让 AI 工具与编程智能体直接处理你的支付运营：查询余额、起草付款、准备对账，并在审查流程下提交——全部经由一个有治理、白名单限定的接口。

它通过 [Streamable HTTP 传输](https://modelcontextprotocol.io/specification/2025-03-26/basic/transports#streamable-http) 暴露单一服务，并用 OAuth 2.1 授权，因此大多数 MCP 客户端会自动完成连接。首次连接时，客户端会打开浏览器窗口以授权 Next PaymentOS。无需 API Key，也无需手动配置 token。

<Info>
**仅限沙盒。** 目前 MCP 接口仅在沙盒环境运行。生产访问需签署合作伙伴合约、通过独立安全审查、通过沙盒测试套件，并指定运营负责人——以上均尚未完成。受监管的结局仍为「合作伙伴审核」或「合规审核」，并受司法管辖区约束。不涉及真实资金流动。
</Info>

## 智能体起草，不放款

MCP 只发布查询、起草、提交三类工具。任何智能体在任何作用域、等级或阶段都不能放款、自行批准或更改策略。每一次放款都需指定负责人。

| 能力 | 谁能执行 |
| --- | --- |
| 查询余额、交易、收款人、状态 | AI 智能体（限定作用域） |
| 起草付款与对账 | AI 智能体（限定作用域） |
| 提交审查 | AI 智能体（限定作用域） |
| 批准 | 仅限指定负责人 |
| 放款 | 仅限合作伙伴控制台，绝不经过 MCP |
