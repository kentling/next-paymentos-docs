# 其他客户端

Next PaymentOS MCP 兼容任何支持 Streamable HTTP 与 OAuth 的 MCP 客户端。

## 配置

1. **打开你的工具的 MCP 设置。** 找到 MCP 或集成相关区域。
2. **添加服务 URL。** 添加一个新的 HTTP MCP 服务并粘贴：

   ```text
   https://api.nextpaymentos.com/mcp
   ```

3. **授权。** 用你的 Next PaymentOS 账户登录以授权访问。

## 使用

连接后，可尝试：

> 查询我的美元余额，并为 *[收款人]* 起草一笔付款以供审查。
