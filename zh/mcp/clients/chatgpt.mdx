# ChatGPT

## 配置

1. **打开 MCP 设置。** 在 ChatGPT 中打开 **设置 > MCP**，并选择添加新服务。
2. **填写服务详情。** 命名为「Next PaymentOS」，并粘贴：

   ```text
   https://api.nextpaymentos.com/mcp
   ```

3. **授权。** 选择 OAuth 并点击 **授权**。用你的 Next PaymentOS 账户登录。

## 使用

连接后，可尝试：

> 查询我的美元余额，并为 *[收款人]* 起草一笔付款以供审查。
