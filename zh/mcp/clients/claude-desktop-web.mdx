# Claude 桌面端与网页端

Next PaymentOS 在 Claude 中作为连接器提供。以下步骤在 Claude 桌面端与网页端均适用。

## 配置

1. 在 Claude 中打开 Next PaymentOS 连接器页面，或前往 **自定义 > 连接器 > 添加 > 浏览连接器** 并选择 **Next PaymentOS**。
2. 点击 **连接**。
3. 用你的 Next PaymentOS 账户登录以授权访问。

<Info>
在 Claude 团队版或企业版套餐中，非管理员可能需要先申请访问权限。
</Info>

## 使用

连接后，可尝试：

> 查询我的美元余额，并为 *[收款人]* 起草一笔付款以供审查。
