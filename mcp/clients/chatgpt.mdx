# ChatGPT

## Setup

1. **Open MCP settings.** In ChatGPT, open **Settings > MCP** and choose to add a new server.
2. **Enter the server details.** Name it "Next PaymentOS" and paste:

   ```text
   https://api.nextpaymentos.com/mcp
   ```

3. **Authorize.** Choose OAuth and click **Authorize**. Sign in with your Next PaymentOS account.

## Usage

Once connected, try:

> Search my USD balance and draft a payout to *[recipient]* for review.
