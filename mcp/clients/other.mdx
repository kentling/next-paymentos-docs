# Other clients

Next PaymentOS MCP works with any MCP client that supports Streamable HTTP and OAuth.

## Setup

1. **Open your tool's MCP settings.** Find the MCP or integrations section.
2. **Add the server URL.** Add a new HTTP MCP server and paste:

   ```text
   https://api.nextpaymentos.com/mcp
   ```

3. **Authorize.** Sign in with your Next PaymentOS account to authorize access.

## Usage

Once connected, try:

> Search my USD balance and draft a payout to *[recipient]* for review.
