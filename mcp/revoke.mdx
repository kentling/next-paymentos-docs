# Revoke access

You can revoke access for any MCP client you have previously authorized.

1. Go to **Settings > MCP** in Next PaymentOS.
2. Under **Connected clients**, find the client you want to revoke.
3. Open the **…** menu next to the client and select **Revoke access**.

The client loses access immediately. You can reconnect at any time by re-authorizing through your MCP client.
